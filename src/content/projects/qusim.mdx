# QuSim: Quantum Circuit Simulator

QuSim is a quantum computing simulator designed to make quantum concepts accessible to students and researchers who don't have access to real quantum hardware.

## Features

- **Circuit Builder**: Drag-and-drop interface for constructing quantum circuits
- **State Visualization**: Real-time Bloch sphere representation of qubit states
- **Algorithm Library**: Pre-built implementations of Grover's, Shor's, VQE, and more
- **Educational Mode**: Step-by-step execution with explanations at each gate
- **Export**: Compatible with Qiskit and Cirq for running on actual quantum hardware

## Technical Approach

The simulator represents quantum states as complex vectors in a 2^n dimensional Hilbert space. Gates are implemented as unitary matrices, with careful attention to numerical stability.

```python
# Example: Creating a Bell state
circuit = Circuit(2)
circuit.h(0)        # Hadamard on qubit 0
circuit.cx(0, 1)    # CNOT from qubit 0 to qubit 1

result = simulator.run(circuit)
# State: (|00⟩ + |11⟩) / √2
```

## Performance

Through sparse matrix representations and JIT compilation, QuSim can efficiently simulate circuits with up to 25 qubits on consumer hardware - enough for exploring most educational and many research scenarios.

## Why I Built This

I wanted to understand quantum computing at a deeper level than textbooks provided. Building a simulator forced me to grapple with every detail: phase conventions, measurement collapse, entanglement. The tool I built for myself became useful for others.
